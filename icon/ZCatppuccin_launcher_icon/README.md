# ZCatppuccin launcher icon

Three editable SVGs are included, following the same launcher-icon split used by the
referenced HeliBoard directory:

- `background_layer_export.svg` — Catppuccin Mocha dark background + subtle mauve glow.
- `foreground_layer_export.svg` — transparent foreground glyph.
- `icon_source_-_rubik_font_not_included.svg` — combined editable source.

The original H-shaped glyph has been changed to `Z`.
The palette is based on Catppuccin Mocha (`base`, `mantle`, `crust`, `mauve`, `text`).

Rubik is referenced but not embedded so the source remains easy to edit.
